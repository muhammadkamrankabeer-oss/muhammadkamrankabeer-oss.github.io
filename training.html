Lab Tracks

Five focused Mini Labs.

Each lab is a structured, hands-on track with one clear outcome: working skills and a GitHub-documented project you built yourself.

LAB · 01

Linux Mini Lab

Beginner → Intermediate

The foundation of every DevOps and cloud career. This lab covers the Linux command line, filesystem, user management, networking, and bash scripting — from absolute scratch to confident daily use.

  • Filesystem hierarchy and navigation
  • User & permission management
  • Process control and systemd services
  • Networking: ip, ss, ufw, firewall rules
  • Bash scripting for automation
  • SSH, SCP, rsync for remote work
  • Final project: automated server setup script
🖥 Hands-on Practice GitHub Repo →
LAB · 02

Docker Deployment Lab

Intermediate

From containers to composed multi-service applications. This lab teaches Docker from the ground up — images, containers, Compose, networking, volumes — placing it directly in the DevOps workflow.

  • Container vs VM fundamentals
  • Building and optimizing Docker images
  • Docker Compose for multi-service apps
  • Volume management and data persistence
  • Container networking deep-dive
  • Health checks and self-healing stacks
  • Final project: containerized full-stack app
🐳 Hands-on Practice GitHub Repo →
LAB · 03

Terraform AWS Lab

Intermediate → Advanced

Infrastructure-as-Code with Terraform on real AWS accounts. Provision EC2 instances, configure VPCs, manage IAM, set up S3 backends, and deploy a complete 3-tier architecture from code.

  • AWS account setup and IAM best practices
  • EC2: launch, connect, configure
  • VPC design: subnets, routing, security groups
  • Terraform state and remote S3 backend
  • Modular Terraform structure
  • Multi-environment deployment (dev/prod)
  • Final project: full 3-tier AWS architecture
☁️ Hands-on Practice GitHub Repo →
LAB · 04

CI/CD GitHub Actions Lab

Intermediate → Advanced

Build a complete CI/CD pipeline using GitHub Actions. From writing your first workflow to multi-stage pipelines with Docker builds, AWS deployments, environment promotion, and automated rollbacks.

  • GitHub Actions workflow basics
  • Build and test automation
  • Docker image builds and ECR push
  • Secrets management best practices
  • Multi-environment deployment (staging/prod)
  • Rollback triggers and safety gates
  • Final project: end-to-end deploy pipeline
🔄 Hands-on Practice GitHub Repo →
LAB · 05

Monitoring Stack Lab

Intermediate → Advanced

Deploy a complete observability stack from scratch. Prometheus scrapes metrics from Linux nodes and Docker containers. Grafana surfaces dashboards. AlertManager fires real notifications.

  • Prometheus architecture and config
  • Node Exporter and cAdvisor setup
  • Scrape configs and label management
  • Grafana dashboard design from scratch
  • AlertManager rules and routing
  • Slack and email alert channels
  • Final project: full monitoring stack on GitHub
