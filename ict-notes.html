1. ICT Basics

ICT stands for Information and Communication Technology. It refers to the technologies used to create, process, store, retrieve, and communicate information. Computers and related digital equipment are common ICT tools.

Why ICT is used

  • To process and manage information.
  • To store data and retrieve it when needed.
  • To communicate and exchange information.
  • To support work, learning, record keeping, and other information tasks.

Data means raw facts or values. Information is data that has been processed or organized so it is useful in a particular context.

Study tip: learn the full form of ICT and the difference between data and information. The source scan is image-based, so check exact textbook definitions against your printed copy.

2. Computer System

A computer is an electronic device that accepts input, processes data according to instructions, stores data or results, and produces output.

StageMeaningExample
InputData or instructions entered into a system.Typing text with a keyboard.
ProcessingOperations performed on input data.Calculating a total.
StorageKeeping data or results for later use.Saving a file to a drive.
OutputInformation presented to the user.Viewing a result on a monitor.

A computer system typically combines hardware, software, data, procedures, and people who operate or use it.

5. CPU and Memory

The Central Processing Unit (CPU) executes program instructions and coordinates many computer operations. Introductory texts commonly describe the CPU in terms of the Control Unit (CU), Arithmetic Logic Unit (ALU), and registers.

  • Control Unit: coordinates instruction execution and directs operations.
  • Arithmetic Logic Unit: performs arithmetic and logical comparisons.
  • Registers: very small, fast storage locations used during processing.

Memory concepts

  • RAM: working memory used by running programs; it is generally volatile, so contents are lost when power is removed.
  • ROM: non-volatile memory used to retain firmware or other essential instructions.
  • Cache: small, high-speed memory that helps the CPU access frequently needed data or instructions.

Memory capacity is measured using units such as bytes, kilobytes, megabytes, gigabytes, and terabytes. Be careful: binary and decimal definitions can differ in technical contexts.

6. Input Devices

Input devices let users or other systems enter data and commands into a computer.

  • Keyboard: enters text, numbers, and commands.
  • Mouse: points, selects, and manipulates on-screen items.
  • Scanner: converts paper documents or images into digital form.
  • Microphone: captures sound.
  • Webcam: captures still images or video.

7. Output Devices

Output devices present processed information to users.

  • Monitor: displays visual information.
  • Printer: produces hard copies on paper.
  • Speakers/headphones: produce audio output.
  • Projector: displays content on a larger surface for a group.

Printers may be grouped into impact and non-impact categories in introductory computer studies. Examples and classification should follow the terms used in your course textbook.

8. Storage Devices

Storage devices retain files, programs, and other data. Unlike volatile RAM, secondary storage is designed to keep data when the computer is turned off.

DeviceKey idea
Hard Disk Drive (HDD)Magnetic storage using rotating platters.
Solid-State Drive (SSD)Flash-based storage with no moving platters.
USB flash drivePortable flash storage connected through USB.
Optical discStores data read using laser technology, for example CD/DVD.

9. Expansion Slots and Cards

Expansion slots are connectors on a motherboard that allow compatible expansion cards to be installed to add or extend computer functions.

  • Graphics card: provides or accelerates graphics output.
  • Network interface card (NIC): provides a network connection.
  • Sound card: supports audio input and output.
  • ISA: an older expansion-bus standard referenced in the source's MCQ material. It is largely obsolete in modern PCs.
  • Drive bay: a physical space in a computer case designed to hold a storage drive or other device.

10. Ports and Connectors

Ports provide connection points for external devices or communication cables. The source MCQ topics include serial ports, PS/2, parallel ports, and RJ-45 connectors.

Port / connectorTraditional use
Serial portTransfers data serially; historically used for modems, terminals, and other peripherals.
Parallel portHistorically used to connect printers and other peripherals.
PS/2Older round connector commonly used for keyboards or mice.
RJ-45 Ethernet connectorCommon connector for wired Ethernet networking.
USBGeneral-purpose interface for peripherals and data transfer.
Older port standards may appear in exams even though current computers often use USB, HDMI, DisplayPort, and network interfaces instead.
