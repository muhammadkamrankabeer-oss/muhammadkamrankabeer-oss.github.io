Computer Science Model Paper

An original practice paper designed around the 2026–2028 syllabus structure. It includes a Computer Systems paper and an Algorithms, Programming and Logic paper. Use it to practise clear explanations, calculations, tracing and program design.

Important: This is an independent practice paper, not an official Cambridge paper or prediction. For the actual exam, follow the syllabus and component details for your session. The official 2210 syllabus lists Paper 1 (Topics 1–6) and Paper 2 (Topics 7–10), each worth 75 marks and 50% of the qualification. Official syllabus.

Paper 1 — Computer Systems

Topics 1–6 · Suggested time: 1 hour 45 minutes · Total: 75 marks · Answer all questions.

Question 1 — Data representation [15 marks]

a) Convert 11010110₂ to denary. Show your working. [4 marks]

b) Convert 173₁₀ to 8-bit binary. [3 marks]

c) State two reasons hexadecimal is used when representing binary data. [2 marks]

d) Explain how resolution and colour depth affect an uncompressed image file size. [3 marks]

e) An 8-bit unsigned register stores 250 and adds 12. Explain what happens to the result in 8 bits. [3 marks]

Question 2 — Data transmission [15 marks]

a) Explain packet switching and give two pieces of information normally included in a packet header. [4 marks]

b) Compare serial and parallel transmission. Give one advantage of serial transmission. [4 marks]

c) Distinguish between half-duplex and full-duplex communication, giving one suitable example of each. [4 marks]

d) Explain how a parity bit can detect an error and state one limitation. [3 marks]

Question 3 — Hardware and software [15 marks]

a) Describe the roles of the control unit and ALU. [4 marks]

b) Explain the fetch–decode–execute cycle. [4 marks]

c) Compare RAM, ROM and cache in terms of use and characteristics. [4 marks]

d) State one difference between a compiler and an interpreter. [3 marks]

Question 4 — Internet, security and emerging technology [15 marks]

a) Explain the role of DNS when a user opens a website using a domain name. [3 marks]

b) Describe two differences between the internet and the World Wide Web. [3 marks]

c) Explain two ways a user can reduce the risk of phishing or account compromise. [4 marks]

d) Describe how a sensor, controller and actuator work together in an automated temperature-control system. [5 marks]

Question 5 — Applied computer systems [15 marks]

Scenario: A school stores student records online and uses an automated gate system.

a) Recommend a suitable storage device for the school's main server and justify your choice. [3 marks]

b) Explain why HTTPS is useful when staff access student records remotely. [4 marks]

c) State one benefit and one risk of using an AI system to flag unusual attendance patterns. [4 marks]

d) Explain why the school should make backups and restrict access to student records. [3 marks]

Paper 2 — Algorithms, Programming and Logic

Topics 7–10 · Suggested time: 1 hour 45 minutes · Total: 75 marks · Answer all questions. Use pseudocode where appropriate and show your working.

Question 1 — Algorithms and testing [15 marks]

a) Define an algorithm and state two characteristics of a good algorithm. [3 marks]

b) Explain the difference between validation and verification. [4 marks]

c) A program accepts an integer from 1 to 20. Give one normal, one boundary and two erroneous test values. [4 marks]

d) Explain the purpose of a trace table and a dry run. [4 marks]

Question 2 — Programming concepts [15 marks]

a) State a suitable data type for each: number of students, average temperature, a single initial, whether a file was found. [4 marks]

b) State the result of 29 DIV 6 and 29 MOD 6. [2 marks]

c) Explain sequence, selection and iteration, with a brief example of each. [6 marks]

d) Explain why meaningful identifiers and comments improve maintainability. [3 marks]

Question 3 — Trace and design [15 marks]

Consider the following pseudocode:

Pseudocode:

total ← 0\nFOR count ← 1 TO 4\n    INPUT value\n    total ← total + value\nNEXT count\nOUTPUT total

a) If the inputs are 3, 5, 2 and 10, what is output? [3 marks]

b) State the value of total after each input has been processed. [4 marks]

c) Explain how the loop works and how the algorithm could also output the average of the four values. [8 marks]

Question 4 — Arrays, subprograms and files [15 marks]

a) Explain two advantages of using an array to store 30 test scores. [3 marks]

b) Describe one difference between a procedure and a function. [3 marks]

c) Explain the difference between a local and a global variable. [3 marks]

d) Give two reasons a program might store data in a file and state one good file-handling practice. [3 marks]

e) Describe how iteration can be used to find the largest value in an array. [3 marks]

Question 5 — Databases and Boolean logic [15 marks]

Scenario: A library database contains BookID, Title, Author, Year and Available.

a) Identify a suitable primary key and justify your choice. [3 marks]

b) Suggest a suitable data type for Available and explain one validation rule for Year. [4 marks]

c) Write a query criterion to select books published after 2020. [3 marks]

d) Complete the truth table for A AND B and A OR B for inputs 00, 01, 10 and 11. [5 marks]

Answer guide and marking points

Use this for self-checking after attempting the paper. These are indicative points for this original practice paper, not an official mark scheme.

Paper 1 — indicative answers

  • Q1: 11010110₂ = 128+64+16+4+2 = 214. 173 = 128+32+8+4+1 = 10101101₂. Hex is compact/readable and maps four bits to one digit. Larger resolution means more pixels; greater colour depth means more bits per pixel. 250+12=262; in 8 bits the stored low 8 bits represent 6, with overflow (262 exceeds 255).
  • Q2: A message is split into packets with destination/source address, sequence or control information. Serial sends bits sequentially; it uses fewer data lines and avoids timing skew across multiple lines. Half-duplex is two-way but one direction at a time; full-duplex is simultaneous. Parity detects some bit errors but may miss an even number of flipped bits.
  • Q3: Control unit coordinates instructions and control signals; ALU performs arithmetic and logic. Fetch instruction from memory, decode, execute, then continue to next instruction. RAM is volatile working memory; ROM is non-volatile startup/firmware storage; cache is small, fast memory for frequently used data. Compiler translates before execution; interpreter translates/executes incrementally.
  • Q4: DNS resolves domain names to IP addresses. Internet is the network infrastructure; Web is a service of linked resources using the internet. Use unique strong passwords, MFA, careful link/domain checks, updates and password managers. Sensor measures temperature; controller compares it with target; actuator switches heater on/off.
  • Q5: SSD may be recommended for speed and reliability; accept justified alternatives. HTTPS encrypts data in transit. AI benefit: earlier detection; risk: false positives, bias or privacy. Backups support recovery; access controls reduce unauthorised exposure.

Paper 2 — indicative answers

  • Q1: Algorithm is a finite sequence of unambiguous steps; good algorithms are correct, clear, finite and efficient. Validation checks acceptability/rules; verification checks accurate copying/transcription. For 1–20: normal 12, boundary 1 or 20, erroneous 0 and 21. Trace tables track variables; dry runs manually execute logic.
  • Q2: Student count INTEGER; temperature REAL; initial CHAR; file found BOOLEAN. 29 DIV 6 = 4; 29 MOD 6 = 5. Sequence runs in order; selection chooses a path; iteration repeats. Meaningful identifiers/comments clarify intent and simplify maintenance.
  • Q3: Output total = 20. Running totals are 3, 8, 10 and 20. The FOR loop repeats four times, count 1 through 4. Average = total / 4, output after the loop.
  • Q4: Array groups same-type scores under one name and allows indexed/iterative processing. Procedure performs a task; function returns a value. Local scope is limited to a subprogram; global scope is broader. Files preserve data between runs; close files correctly and handle missing files/errors. Initialise largest to first item, then loop through remaining items and update when a larger value is found.
  • Q5: BookID is a suitable unique primary key. Available can be BOOLEAN; Year could be an integer with a plausible range rule. Query criterion: Year > 2020. AND outputs 0,0,0,1 for 00,01,10,11; OR outputs 0,1,1,1.
