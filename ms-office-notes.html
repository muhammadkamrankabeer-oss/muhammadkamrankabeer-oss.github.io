1. Office Automation

Office Automation means using computers and software to perform office tasks more quickly and consistently. It helps users create, edit, store, organize, and share documents while reducing repetitive manual work.

Why is Office Automation useful?

  • It can make routine office work faster.
  • It helps prepare and revise documents.
  • It supports storing, retrieving, and sharing information.
  • It can improve consistency and reduce repetitive manual effort.

4. Ribbon, Tabs, Groups, and Commands

  • Ribbon: the main command strip near the top of the application window.
  • Tab: a category of tools, such as Home or Insert.
  • Group: related commands arranged together on a tab.
  • Dialog Box Launcher: a small arrow in a group that opens more settings.
  • Contextual Tab: a tab that appears when a particular object, such as a picture or table, is selected.
  • Ribbon display/view option: changes how much of the Ribbon is visible.

Examples of commands

Common Word commands include Cut, Copy, Paste, Bold, Italic, Underline, font size, text alignment, Insert Picture, Save, and table-related commands.

Remember the difference: a tab organizes a category of tools; a group organizes related commands within that tab.

5. Word Processing, Editing, and Shortcuts

Word processing is using software to create, edit, format, save, and print text documents. A word processor can also support tables, pictures, and spelling or grammar checking.

Common editing commands

  • Cut: removes selected content from its current location and places it on the clipboard.
  • Copy: leaves the original content in place and copies it to the clipboard.
  • Paste: inserts clipboard content.
  • Undo: reverses the previous action.
  • Save: saves changes to the current file.
  • Save As: creates a copy under a new name, format, or location.
  • Find: searches for text in a document.

6. Text Formatting and Page Formatting

Text formatting

Text formatting changes the appearance of characters and paragraphs. Examples include font family, font size, bold, italic, underline, font colour, and alignment.

Page formatting

Page formatting controls the layout of a page. The material discusses margins, orientation, paper layout, and columns.

  • Portrait: the page is taller than it is wide.
  • Landscape: the page is wider than it is tall.
  • Margins: blank spaces around the edges of the page.
  • Bullets and numbering: tools for creating organized lists.
  • Header: content area at the top of a page.
  • Footer: content area at the bottom of a page.
  • Text box: a movable container for text.

7. Working with Tables

Tables arrange information in rows and columns. In Word, the material describes creating and modifying tables through the Insert tab and Table Tools.

  1. Open the Insert tab and select Table.
  2. Select the desired number of rows and columns from the grid, or choose Insert Table to enter the counts.
  3. Click in a table to access contextual table tools, including a Layout tab in the version described.
  4. Use AutoFit to adjust column widths to the contents or available page width.

Table operations

  • Insert row: use the table layout tools to insert above or below the selected row.
  • Insert column: use the table layout tools to insert left or right.
  • Delete: remove selected rows or columns using the delete options.
  • Merge cells: combine two or more cells into one larger cell.
  • Split cells: divide a cell into multiple rows or columns.
  • Resize: drag row or column edges, or use the table layout settings.

8. Printing and Templates

  • Print Preview: shows how a document is expected to look when printed so that layout issues can be checked first.
  • Print settings: allow the user to select a printer and adjust print options before printing.
  • Template: a prepared document design that can be reused as a starting point for similar documents.

Basic print workflow

  1. Save the document.
  2. Open the Print command, commonly with Ctrl + P.
  3. Review the preview and check page orientation, margins, and page range.
  4. Select the printer and required settings.
  5. Print when the preview and settings are correct.

9. Urdu Typing in Windows and Word

The uploaded material includes basic steps for enabling Urdu input and switching keyboard languages.

  1. Open Windows Settings and go to Time & Language / Language settings.
  2. Choose the option to add a language and select Urdu, then complete the setup.
  3. Switch between installed input languages using Windows + Space. Some Windows setups also support Alt + Shift.
  4. Open Word, switch to the Urdu keyboard, and type. Choose an appropriate Urdu font if needed.

Pak Urdu Installer: the source describes this as a utility used on some older Windows systems to support Urdu language input and keyboard use.

The exact Settings labels and language-switching shortcuts can differ between Windows versions and configurations.

10. Excel Macros

The later pages of the uploaded scan describe macros in Excel, the Developer tab, recording a macro, and adding a macro command to the Ribbon.

Macro: a saved sequence of actions that Excel can run to automate repetitive work. The scan identifies VBA (Visual Basic for Applications) as the programming language associated with many Excel macros.

Concepts to remember

  • Purpose: automate repeated steps, such as applying a consistent format or carrying out a routine task.
  • Developer tab: contains macro-related tools; it may need to be enabled in Excel options.
  • Record Macro: starts recording the actions that Excel will store.
  • Stop Recording: ends the recording so the sequence can be saved.
  • Run a macro: executes the recorded or written sequence of actions.
  • Macro-enabled workbook: use a format that preserves macros, such as .xlsm, when required.
  • Relative references: make recorded actions work relative to the active cell or position.
  • Absolute references: keep the referenced cell or location fixed when copied or used.

General workflow to record a macro

  1. Open Excel and enable the Developer tab if it is not visible.
  2. Select Record Macro and enter a meaningful name.
  3. Perform the actions you want to automate.
  4. Choose Stop Recording.
  5. Save the workbook in a macro-capable format if the macro must be retained.
  6. Test the macro on suitable data before relying on it.
Security: only enable or run macros from sources you trust. A macro can change workbook content and may perform unwanted actions.
