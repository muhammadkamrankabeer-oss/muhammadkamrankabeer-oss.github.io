1Data representation

Computers store and process information using binary because electronic circuits can reliably represent two states: on/off or high/low voltage.

Number systems

Denary uses digits 0–9 (base 10); binary uses 0 and 1 (base 2); hexadecimal uses 0–9 and A–F (base 16). Each binary digit is a bit. Four bits correspond to one hexadecimal digit.

Binary arithmetic and shifts

An 8-bit unsigned value ranges from 0 to 255. Adding two 8-bit values can overflow if the result needs a ninth bit. A logical left shift moves bits left and fills the right with zero; a right shift moves bits right and fills the left with zero.

Text, images and sound

Character codes map characters to numbers. ASCII represents a limited character set; Unicode supports a much wider range. Image file size depends mainly on resolution and colour depth. Uncompressed sound size depends on sample rate, bit depth/resolution, duration and number of channels.

Worked example / key idea: Binary 101101₂ = 32 + 8 + 4 + 1 = 45₁₀. A 3-bit colour depth allows 2³ = 8 possible colours per pixel.

2Data transmission

Data is sent between devices through a communication medium. The method chosen affects speed, reliability, cost and security.

Packets

Packet switching divides a message into packets. Each packet carries addressing and sequencing information; packets may travel by different routes and are reassembled at the destination.

Transmission modes

Serial sends bits one after another; parallel sends several bits simultaneously. Simplex is one-way, half-duplex allows both directions but not simultaneously, and full-duplex allows both directions simultaneously.

Errors and checks

Parity adds a bit to help detect some errors; a checksum compares calculated values; echo checking sends data back for comparison. Encryption protects confidentiality but does not by itself prove that data has arrived correctly.

Worked example / key idea: A video call usually benefits from full-duplex communication. Packet switching helps networks route data around congestion or failed paths.

3Hardware

Hardware is the physical equipment of a computer system. Components work together to input, process, store and output data.

CPU

The control unit coordinates operations; the ALU performs arithmetic and logical operations; registers are very fast small storage locations used during processing.

Fetch–decode–execute

The CPU fetches an instruction from memory, decodes what it means, then executes it. The program counter tracks the next instruction address; the address and data registers help move instructions and data.

Memory and storage

RAM is volatile working memory. ROM is non-volatile and commonly stores startup instructions. Cache is small, fast memory close to the CPU. Secondary storage such as SSDs and HDDs retains data without power.

Worked example / key idea: More cache can reduce the time spent waiting for frequently used data. More RAM helps when many programs or large data sets are active, but RAM does not replace permanent storage.

4Software

Software is a set of instructions and related data. System software operates or manages the computer; application software helps users complete tasks.

Operating systems

An OS provides a user interface and manages memory, processes, files, devices and user accounts. It allocates resources and helps prevent programs from interfering with each other.

Utility software

Utilities perform maintenance or protection tasks, such as anti-malware scanning, backup, compression, encryption and disk checking.

Translators

A compiler translates a whole high-level program before execution; an interpreter translates and executes instructions one at a time; an assembler translates assembly language into machine code.

Worked example / key idea: A compiler can produce a standalone executable and report several errors after compilation; an interpreter can stop when it reaches an error during execution.

5The internet and its uses

The internet is a global network of interconnected networks. The World Wide Web is a service that uses the internet; the terms are not interchangeable.

Addressing and services

An IP address identifies a device or network interface for routing. DNS translates human-readable domain names into IP addresses. A URL identifies a resource and its location.

Protocols

HTTP/HTTPS are used for web communication; HTTPS uses encryption through TLS. Email commonly uses SMTP to send messages and IMAP or POP3 to retrieve them. FTP is used for file transfer.

Security and impacts

Phishing tricks people into revealing information. Malware includes viruses, worms, Trojans and ransomware. Use strong unique passwords, multi-factor authentication, updates, backups and careful link checking.

Worked example / key idea: A browser requests web resources from a server. DNS can help find the server's IP address; HTTPS helps protect data in transit.

6Automated and emerging technologies

Automation uses control systems to carry out tasks with limited human intervention. Sensors collect input; processors compare readings with programmed conditions; actuators carry out actions.

Robotics and control

A feedback system measures the output and adjusts its actions. A thermostat, for example, compares a temperature reading with a target and switches heating on or off.

Artificial intelligence

AI systems perform tasks associated with intelligent behaviour. An expert system uses a knowledge base, rule base, inference engine and user interface. Machine learning uses data to learn patterns or adjust behaviour.

Benefits, risks and ethics

Automation can improve speed, consistency and safety but may cause job displacement, privacy concerns, bias, dependence on systems or high setup costs. Decisions should consider fairness, accountability, safety and sustainability.

Worked example / key idea: A temperature sensor is an input device; a heater is an actuator/output. In a feedback loop, the measured temperature is used to decide whether heating should continue.

7Algorithm design and problem-solving

An algorithm is a finite, ordered set of unambiguous steps for solving a problem. A good solution is correct, efficient and testable.

Design tools

Flowcharts show control flow using standard symbols. Pseudocode describes an algorithm in a language-independent structured form. Trace tables track variable values and conditions step by step.

Core structures

Sequence runs instructions in order. Selection chooses between paths (IF/ELSE or CASE). Iteration repeats instructions using a count-controlled or condition-controlled loop.

Testing and validation

Normal data is typical, boundary data tests limits, and erroneous data should be rejected. Validation checks whether data is sensible; verification checks that data was copied or entered accurately. Dry runs help locate logic errors.

Worked example / key idea: For a loop that accepts marks from 0 to 100, test 0 and 100 as boundary values, 57 as normal data, and -1 or 101 as erroneous data.

8Programming

Programming turns an algorithm into instructions a computer can execute. The syllabus expects understanding of variables, data types, control structures, arrays, subprograms and files.

Variables and types

A variable stores a value that may change; a constant is intended to remain fixed. Common types include INTEGER, REAL, CHAR, STRING and BOOLEAN. Input receives data and output presents results.

Operators and control

Arithmetic operators include +, -, *, /, ^, DIV and MOD. Relational operators compare values; AND, OR and NOT combine or reverse Boolean conditions. Selection and iteration control program flow.

Subprograms and arrays

A procedure performs a task; a function returns a value. Parameters pass information to subprograms. Local variables exist within a subprogram; global variables are accessible more broadly. Arrays store multiple related values under one name.

Files and maintainability

Files allow data to persist after a program ends. Programs should open and close files correctly, use meaningful identifiers, comments and subprograms, and test normal, boundary and erroneous cases.

Worked example / key idea: DIV gives the integer quotient and MOD gives the remainder: 17 DIV 5 = 3; 17 MOD 5 = 2. A count-controlled loop is suitable when the number of repetitions is known.

9Databases

A database stores organised data so it can be searched, updated and managed consistently.

Tables and fields

A table contains records (rows) and fields (columns). Each field should have an appropriate data type such as text, integer, date or Boolean.

Keys and validation

A primary key uniquely identifies each record and must not be duplicated. Validation rules can check range, presence, length, format or lookup values.

Queries and reports

A query retrieves records that match criteria, such as Score >= 50. Sorting arranges records; a report formats selected information for people to read.

Worked example / key idea: A StudentID is often a better primary key than a student's name because two students may share the same name.

10Boolean logic

Boolean values are TRUE and FALSE. Logic gates implement Boolean operations and can be combined into circuits.

Basic gates

AND outputs TRUE only when both inputs are TRUE. OR outputs TRUE when at least one input is TRUE. NOT reverses its input.

Other gates

NAND is the inverse of AND; NOR is the inverse of OR. XOR outputs TRUE when the inputs differ.

Truth tables

A truth table lists every possible input combination and the corresponding output. With n binary inputs, there are 2ⁿ input combinations.

Worked example / key idea: For A=1 and B=0: AND=0, OR=1, NOT A=0, XOR=1. Always calculate each gate from its inputs rather than guessing from the circuit's appearance.

How to prepare effectively

Learn actively

After reading a section, close the page and explain the concept in your own words. Draw diagrams, truth tables and flowcharts from memory.

Practise application

For every definition, practise a question asking you to explain, compare, calculate, trace or recommend. Examiners often award marks for applied reasoning, not a memorised phrase alone.

Show working

For number conversions, trace tables and logic circuits, show intermediate steps. If an answer is wrong, your working can help you find the exact mistake.
